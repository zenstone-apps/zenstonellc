# zenstonellc.com

Website und Datenschutzerklärung für die Apps von ZenStone LLC
(Calm Stoic Journal, KnowUs: Who Knows Who, Hairstyle AI).

Gehostet über GitHub Pages. Jeder Push auf `main` geht live — vorher lief die
Seite auf Netlify, dort waren Deploys wegen einer kontoseitigen Credit-Sperre
blockiert.

## Dateien

| Datei | Zweck |
|---|---|
| `index.html` | Startseite |
| `privacy.html` | Datenschutzerklärung, erreichbar unter `/privacy` |
| `google…html`, `tiktok…txt` | Domain-Verifizierung für Google und TikTok — nicht löschen |

## Ändern

Datei bearbeiten, committen, pushen. Die Links innerhalb der Seiten nutzen
saubere URLs (`/`, `/privacy`) — bei GitHub Pages funktioniert das nur, wenn die
Datei `privacy.html` heisst und über `/privacy` aufgerufen wird, was Pages
automatisch auflöst.
